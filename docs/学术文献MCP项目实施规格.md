# 面向毕业设计的学术文献 MCP 项目实施规格

版本 1.1　日期 2026 年 10 月 19 日

本次修订补充第 19 节“第二版可选文献综述辅助方案”，并同步明确用户选择、交付与验收边界。新增开关、数据实体、接口及工作流均为待实现设计，不表示当前程序已具备这些能力；已实现功能和真实验证结果以《架构与工具契约》和《验收状态》为准。

本项目建设一个本地运行的学术文献 MCP 服务，让支持本地 MCP 的 Agent 能够在机构允许的范围内检索中国知网、获取摘要与题录、筛选和整理文献、处理授权全文，并在用户选择综述辅助时形成能够回查原文的综述草稿。服务面向经管、计算机、电气、电子信息及理科毕业设计，先交付单用户、单校试用版。

首版认证固定为两种模式：校内网或学校 VPN，以及 CARSI。VPN 由用户事先连接，CARSI 的学校登录、扫码和多因素认证由用户在浏览器中完成。项目负责管理独立会话、识别机构、检查操作权限和恢复任务。研究判断由学科规则与证据支持，筛选阈值允许关闭、调整和复核。

本文用于需求评审、任务拆分、开发联调和验收。文中的需求编号是后续任务、测试和缺陷记录的追踪标识；建议数值是试点起始设置，验收目标需用独立样本实测。学校档案、自动化许可和真实登录结果在试点阶段确认，不以模拟结果替代。

## 1 产品范围与交付边界

### 1.1 首版交付

| 编号 | 交付内容 | 完成标准 |
| --- | --- | --- |
| ACC | 两种机构访问模式 | 校内网或学校 VPN 与 CARSI 分别通过真实学校验证，并能识别失效与机构不符 |
| SEA | 知网检索与详情 | 支持受控检索入口、分页、题录和摘要，保留检索式与来源 |
| DED | 去重与版本管理 | 精确重复可合并，近似重复待核查，版本与文件可追溯 |
| QUA | 可选筛选 | 年份、类型、名单、引用与学科方法规则可配置，排除理由可查看 |
| CIT | 参考文献 | 确定性生成引文并导出 RIS、BibTeX、CSL JSON 和格式化文本 |
| FUL | 授权全文 | 在许可允许时下载并校验文件，同时支持导入用户合法取得的文件 |
| PAR | 全文阅读 | 文本 PDF 可检索，扫描件按需 OCR，保留页码与解析版本 |
| REV | 可选证据综述 | 用户选择后生成文献矩阵、综述草稿、引用清单和证据不足说明；第二版扩展见第 19 节 |

初期以 Windows 本地运行为主要验证环境，使用一个试点学校档案和一个受控 CNKI 检索入口。学科差异通过检索词表、评价模板和配置体现，模型提供方可替换。

综述辅助由用户自行选择，不作为检索、导入、去重、筛选、单篇全文阅读和参考文献导出的前置条件。第二版拟新增项目级开关，默认关闭，详细选择规则见第 19.2 节；开发交付某项工具不等于每次研究任务都必须执行该流程。

### 1.2 后续范围

远程多人共享、跨校自动适配、学校账号托管、VPN 客户端管理、各校 WebVPN 专属改写、全量抓取、付费购买、CAJ 自动转换和 Word 动态引文字段生成，安排在首版之后。首版生成参考文献文本和题录；Word 动态引文可配合 Zotero 的现有插件工作流使用。

WebVPN 不新增为第三种认证模式。如果用户从学校正常入口进入知网，且通用浏览器会话能正常操作，可以复用该会话；不兼容时返回明确状态，引导使用校内网、学校 VPN 客户端或 CARSI。

### 1.3 接入能力的前置条件

机构身份、资源订阅、自动化操作和内容处理分别核验。普通学校账号能够浏览或下载，不直接证明允许机器人检索、自动下载、本地建立全文索引或发送第三方模型。部分高校公开规则禁止自动下载，必须核验试点学校和数据商实际条款。[S1][S7][S8]

每项能力只有在适用许可和实际访问均允许时启用。若在线接入尚未具备条件，可先开发导入后的处理链路，但此时在线知网检索与下载仍记为未验收。官方数据接口保留为适配器扩展点，首版不将尚未取得的接口凭据作为既有条件。[S9]

## 2 用户操作与系统输出

### 2.1 标准操作流程

1. 用户选择学校档案与认证模式，查看已确认的资源范围和可用操作。
2. 校内网或 VPN 用户先完成网络连接；CARSI 用户在专用浏览器完成学校认证。
3. 系统检查知网是否识别目标机构，显示检查结果和时间。
4. 用户向 Agent 提出研究问题，选择文献类型、时间窗和筛选强度，并自行决定是否启用综述辅助。
5. Agent 生成检索计划，调用 MCP 检索、读取详情并写入本地文献库。
6. 系统执行去重和元数据筛选，返回保留、待核查与排除清单。
7. 对选定文献检查全文权限，下载或导入文件，解析并建立可定位的证据记录。
8. 用户选择综述辅助时，Agent 整理文献卡和主题比较，按章节形成草稿，系统检查引用身份和证据定位；未选择时可在检索、整理或阅读后直接导出。
9. 导出用户需要的参考文献和运行记录；启用综述辅助的任务还可复核重点论断，并按需导出文献矩阵、综述草稿和核查清单。

示例任务为研究课题检索近五年文献，保留经典研究，选择若干文献阅读全文，再按研究方法和结论差异整理综述。候选数量和全文数量受用户预算、实际许可及来源可用性共同约束。

该示例包含可选综述步骤，不代表所有用户均需生成综述。第二版扩展按第 19 节分阶段实现，不能将上述目标流程全部计为当前已完成能力。

### 2.2 按用户选择提供的交付文件

只交付本次实际执行步骤的产物。未启用综述辅助时，不要求生成文献矩阵、综述草稿、主题比较或论断核查清单。

| 文件或记录 | 应包含的内容 |
| --- | --- |
| 检索记录 | 检索式、入口、过滤条件、排序、获取时间、实际页数、截断原因 |
| 筛选清单 | 文献标识、阶段、结果、命中规则、缺失项、规则版本、人工覆盖记录 |
| 文献矩阵（可选综述产物） | 问题、对象、方法、数据或实验、结果、限制、证据定位、阅读层级 |
| 综述草稿（可选综述产物） | 按问题组织的综合分析、分歧与条件、引用和证据不足说明 |
| 参考文献 | 实际使用的发表版本、完整度提示、样式标识与版本 |
| 运行记录 | 输入、任务状态、组件版本、模型调用统计和可恢复进度 |

## 3 技术架构与组件选择

### 3.1 模块分工

Agent 负责理解研究问题、拟定检索计划和撰写综合分析；MCP 负责可验证的数据获取、规则执行、记录持久化和证据读取。首版不在 MCP 内另建一套完整 Agent 调度系统，避免重复调用模型和难以追踪费用。

| 模块 | 负责的工作 | 主要依赖 |
| --- | --- | --- |
| MCP 接口层 | 参数校验、结构化返回、资源读取、任务查询 | 官方 Python MCP SDK |
| 学校与会话模块 | 两模式接入、机构识别、会话隔离、状态恢复 | Playwright 专用浏览器上下文 |
| 来源适配器 | 检索、详情、导出和获准下载 | CNKI 页面或已获准接口 |
| 文献数据层 | 来源字段、作品版本、文件、解析和证据 | SQLite 与本地文件目录 |
| 去重与筛选模块 | 精确匹配、候选关联、规则与学科评价 | 可版本化规则和可选模型 |
| 解析与证据模块 | 版面、OCR、章节、页码和片段检索 | PDF 解析器与可选 MinerU |
| 引文与导出模块 | 样式渲染、题录导出、Zotero 关联 | 经验证的 CSL 渲染器 |
| 任务模块 | 排队、取消、部分完成、恢复与幂等 | SQLite 持久任务记录 |

数据流为 Agent 调用 MCP，MCP 检查许可和会话后调用来源适配器，结果进入本地文献库；筛选后的选定文献按用户请求进入全文获取与解析；Agent 通过证据接口读取内容，用户选择综述任务时再形成矩阵和综述。

### 3.2 首版技术决定

采用 Python 3.12 作为试点运行环境，以官方 MCP SDK 实现本地 stdio 服务。采用 Playwright 管理项目专用浏览器。普通结构数据使用 SQLite，文件使用内容哈希命名并记录数据库关联。首版以关键词检索和片段索引为基础，语义检索与重排作为可替换模块；模型、提示词和嵌入版本必须写入运行记录。[S10][S11]

复杂扫描件、双栏、公式和表格按文档类型选择解析器；先抽样验证，再锁定版本。GROBID 可作为参考文献和结构提取的可选组件。Zotero 通过明确的 API 适配器关联，不能直接改写其数据库。[S14][S15][S18]

### 3.3 相关开源项目取舍

Stars 为 2026 年 10 月 19 日调研快照约数。功能说明来自仓库与部分源码核验，实际学校可用性仍需验证。

| 项目 | Stars 与许可 | 采用方式 |
| --- | --- | --- |
| Jasminum | 约 7.3k AGPL 3.0 | 可选 Zotero 中文元数据和附件生态依赖，CAJ 附件关联不等于解析 [S12] |
| zotero mcp | 约 5.5k MIT | 参考文献库查询、全文读取和工具边界 [S13] |
| paper search mcp | 约 2.9k MIT | 参考多源论文模型和错误结构，仅保留授权来源 [S16] |
| PaperQA2 | 约 9.4k Apache 2.0 | 参考检索片段与证据回答流程，作为原型比较基线 [S17] |
| MinerU | 约 82k 附加许可 | 复杂版面和 OCR 候选，按任务路由并履行当前许可 [S14] |
| cnki skills | 998 许可待核实 | 浏览器流程参考，复用代码前核验独立授权文件 [S19] |
| SepineTam cnki mcp | 约 50 GPL 3.0 | 学校档案与检索设计参考，仓库明确不提供全文下载 [S20] |

2026-10-20 补充的检索与筛选增强设计见第 20 节，详细来源、当前代码缺口和接口草案见[文献检索与筛选融合调研](文献检索与筛选融合调研.md)。这些新增设计尚未实现或验收，不改变第 3.3 节原有星数快照日期，也不将上游项目表现当作本项目实测结果。

## 4 学校档案与授权能力

### 4.1 学校配置字段

| 字段 | 说明 | 校验规则 |
| --- | --- | --- |
| institution_id | 本地稳定学校标识 | 唯一且不随显示名称变化 |
| display_names | 中英文学校名和已确认别名 | 不用模糊简称自动判定机构 |
| access_modes | institution_network 与 carsi | 仅启用学校真实支持的模式 |
| entry_urls | 学校资源入口和知网入口 | HTTPS 优先，来源可追溯 |
| carsi_entry | 当前有效的官方校外访问入口 | 启用 CARSI 前人工核验 |
| allowed_hosts | 已核验的知网与学校 IdP 主机 | 精确主机或受控子域规则 |
| institution_rules | 页面机构标签及匹配规则 | 保存依据和规则版本 |
| subscriptions | 子库、资源类型、年份范围 | 已确认与未知范围分开 |
| policy_records | 各操作的许可和依据 | 范围、有效期、核验人或角色 |
| verified_at | 档案最后核验时间 | 页面或条款变化后重新核验 |

学校尚未确定时，只建立配置结构和待核验清单，不填造机构信息。身份页面允许用户手动选择学校；不通过抓取学校登录表单或保存账号密码实现自动提交。

### 4.2 操作许可

| 能力标识 | 操作范围 |
| --- | --- |
| automated_search | 自动提交检索、翻页和读取结果 |
| metadata_collect | 采集或导出题录与摘要 |
| fulltext_download | 自动获取全文文件 |
| local_parse_index | 在本地解析并建立全文索引 |
| external_model_use | 向指定外部模型服务发送允许内容 |

每项取值为 allowed、denied 或 unknown，并记录许可来源、适用资源、适用主体、有效期、速率要求和核验时间。学校订阅、数据商许可、用户资源权限与项目配置共同决定有效操作范围。未知状态需完成核验后再启用对应操作。

若自动下载被拒绝或未核实，系统提供正常网页定位和人工下载后导入。全文能下载但不允许外部模型处理时，证据读取也必须执行模型出站策略，不能仅靠文件保存在本地来推断可发送。

运行配置登记客户端处理档案，说明接收方是本地模型、校内服务或指定外部服务，以及允许接收的内容类别。所有工具和资源输出中的受限摘要、正文、证据片段与含原文的解释统一经过出站检查；接收位置未知时只返回允许的元数据和状态。该约束保证 MCP 自身输出边界，不宣称控制 Agent 使用其他文件或网络工具的行为。

## 5 校内网和学校 VPN 接入规格

### 5.1 正常流程

1. 用户选择 institution_network 模式及学校档案。
2. 系统说明需要连接校园网，或由用户完成学校 VPN 客户端连接；项目不管理 VPN 软件。
3. 在项目专用浏览器中打开学校允许的资源入口或知网页面。
4. 如学校入口要求统一认证，用户亲自完成，系统保持等待。
5. 系统执行只读检查：页面可达、目标机构标签、登录提示及冲突信息。
6. 机构可靠匹配后，会话变为 ready，返回机构名称、检查时间和脱敏证据摘要。
7. 后续检索、详情和全文各自检查许可、会话有效性和资源状态。

本机出现内网 IP、存在 VPN 进程或知网首页能打开，都不能作为机构认证成功的依据。默认不调用外部 IP 查询网站。网络条件变化时，对下一次受控操作重新检查；需要指定论文权限时使用真实资源检查，不为探测而下载无关全文。

### 5.2 异常与兼容性

普通外网能打开知网但未识别机构时，返回 AUTHENTICATION_REQUIRED 或 INSTITUTION_UNVERIFIED。网络不可达返回 NETWORK_NOT_READY。识别到其他机构返回 INSTITUTION_MISMATCH。用户已经通过学校 WebVPN 进入知网时，仅在通用浏览器操作可运行的条件下复用；代理域名或下载不兼容返回 PROXY_SESSION_INCOMPATIBLE。

项目为两种模式保存独立会话上下文。未经用户选择，不切换学校、认证模式或账号；重新连接网络后可重新验证并恢复已保存的研究任务。

## 6 CARSI 接入规格

### 6.1 正常流程

1. 用户选择 carsi 模式和学校档案；系统检查该学校是否已确认开通知网 CARSI。
2. 打开经过核验的知网官方校外访问入口，用户选择目标学校。
3. 浏览器跳转至学校身份提供方，用户完成密码、扫码、MFA、属性释放和条款确认。
4. 系统等待返回知网，不读取密码、验证码或完整身份断言。
5. 返回后检查目标机构标签、登录状态和冲突提示。
6. 检查通过后变为 ready，并保存脱敏检查记录。

CARSI 入口地址与学校跳转主机随档案配置。学校不在可选范围、未开通对应资源或用户身份不符合要求时，返回明确原因；由用户决定是否改用另一模式。

### 6.2 登录页处理

登录页由用户操作。Agent 只接收“正在等待用户完成认证”等状态，不获得完整登录页 DOM、未脱敏截图、cookie、Authorization 或 SAML 断言。跳转主机超出学校已核验列表时暂停，核验目标后再恢复；不能简单允许全部 edu.cn 或任意重定向地址。

验证码、扫码和 MFA 属于用户交互状态，不实现识别、代答或连续自动提交。等待用户期间不消耗轮询式模型调用；用户完成后主动调用会话验证接口。

### 6.3 会话复用和退出

允许复用项目自行创建且用户已登录的专用上下文，不读取日常浏览器的历史记录或任意个人配置。默认短期会话；启用持久保存时，将可序列化会话状态使用操作系统保护的存储加密，并限制目录权限。若持久浏览器目录中仍含未受保护的敏感状态，首版禁用该持久方式。

退出清除项目持有的本地会话和临时凭据；需要时打开正常退出入口。退出结果应准确说明已清除的范围，不宣称退出学校所有统一认证会话。

## 7 会话状态和错误恢复

### 7.1 三类状态独立保存

身份会话、资源访问和操作许可独立建模。会话 ready 仅表示目标机构已识别且当前可用；单篇资源仍可能未订购，自动操作仍可能未获许可。

| 会话状态 | 含义 | 下一步 |
| --- | --- | --- |
| not_started | 尚未建立会话 | 用户选择模式并启动 |
| waiting_for_user | 等待网络或用户交互 | 用户完成后提交验证 |
| verifying | 正在检查机构状态 | 返回 ready 或明确原因 |
| ready | 目标机构已可靠识别 | 按许可执行具体操作 |
| paused | 机构不符、代理不兼容或访问频繁 | 解决原因后重新检查 |
| expired | 原可用会话已失效 | 重新认证并恢复任务 |
| closed | 本地会话已关闭或清除 | 新建会话 |

主要转换为 not_started 到 waiting_for_user，到 verifying，再到 ready。需要交互时回到 waiting_for_user；运行中失效进入 expired；用户处理后重新验证。任意状态可由用户关闭。暂停和失效时停止新增网络操作，保留已完成记录。

单篇资源状态使用 unknown、available、not_subscribed、unavailable、manual_required。available 仅表示当前访问证据支持获取，还需检查自动获取和后续处理许可。错误码和状态分别返回，避免所有失败都显示为登录失败。

### 7.2 错误码

| 错误码 | 判断含义 | 恢复动作 |
| --- | --- | --- |
| NETWORK_NOT_READY | 网络或入口不可达 | 用户检查校园网或学校 VPN |
| BROWSER_SESSION_UNAVAILABLE | 专用浏览器已关闭或丢失 | 重建项目会话 |
| PROXY_SESSION_INCOMPATIBLE | 当前代理无法执行通用操作 | 用户选择受支持路径 |
| AUTHENTICATION_REQUIRED | 尚无机构身份 | 用户完成机构登录 |
| USER_INTERACTION_REQUIRED | 需要扫码 MFA 或验证码 | 暂停等待用户 |
| INSTITUTION_UNVERIFIED | 证据不足以确认学校 | 核验入口和识别规则 |
| INSTITUTION_MISMATCH | 实际机构与学校档案不符 | 重新选择或认证 |
| SESSION_EXPIRED | 原会话已失效 | 原模式重新认证 |
| RESOURCE_NOT_SUBSCRIBED | 该资源不在可访问范围 | 保留题录并提示正常获取渠道 |
| ACCESS_UNDETERMINED | 无法判断资源权限 | 保持 unknown |
| POLICY_UNVERIFIED | 对应操作许可未知 | 核验或人工处理 |
| OPERATION_NOT_PERMITTED | 对应操作已明确被禁止 | 停止该操作 |
| PROVIDER_RATE_LIMITED | 来源提示访问频繁 | 遵守提示暂停并保留进度 |
| PROVIDER_UNAVAILABLE | 来源临时故障或维护 | 有限重试或稍后恢复 |
| SOURCE_LAYOUT_CHANGED | 页面结构与预期不符 | 停止采集并更新适配器 |
| FILE_VALIDATION_FAILED | 获取文件格式或完整性不符 | 不标为成功并保留安全诊断 |

错误结果统一包含 code、message、user_action、retryable、requires_user_action、job_id 和 request_id。retryable 表示具备恢复可能，不等于系统可以自动重试。普通临时网络故障最多自动重试两次并退避；登录、验证码、条款限制、频繁访问提示不走自动重试。

## 8 检索和题录规格

### 8.1 检索输入

支持主题、题名、关键词、作者、来源、年份、文献类型和排序。高层检索输入先转为受控表达式，再映射到实际入口；专业检索式提供可选入口并验证长度、字段及语法。不开放任意脚本、任意请求或浏览器执行参数。

Agent 可提出中文同义词、英文对应词及学科词扩展。系统保存用户原始问题、最终检索式与每次修改。相关性、最新和被引排序可按预算取并集；运行记录必须标明只取得前若干页时的覆盖范围，不将其称为全库穷尽检索。

### 8.2 分页与快照

每次查询绑定 query_id、学校档案、来源入口、查询条件和获取时间。next_cursor 使用服务管理的游标，不向 Agent 暴露含敏感参数的原始页面地址。停止条件包括用户数量预算、来源末页、许可预算、超时、会话变化或页面异常。记录实际读取页数和停止原因。

检索结果变化时，以获取时间和来源记录解释差异，不承诺不同日期返回完全相同的排序。可重放指相同输入和组件版本能复现处理规则；来源数据变化另行记录。

### 8.3 题录字段与补充来源

核心字段为来源标识、题名、作者、年份、文献类型、来源刊会或学校、详情地址；摘要、关键词、DOI、卷期页、机构、基金、引用量和名单标签为可缺失字段。每个字段保存来源、获取时间和核验状态，缺失值使用显式状态，不由模型补造。

外部元数据补充作为 P1 能力。OpenAlex 和 Crossref 用于匹配标识、元数据和引用关系，Crossref 与 Retraction Watch 可提供更新和撤稿线索；中文无 DOI 文献的覆盖率需实测。没有命中撤稿记录只表示尚未发现，不能当作未撤稿证明。摘要和全文许可与元数据许可分别处理。[S22][S23]

### 9.1 实体关系

| InstitutionProfile | id 名称 入口 规则版本 | 关联会话和许可 |
| AccessSession | 模式 机构状态 上下文引用 | 绑定本地使用者与学校 |
| ClientProcessingProfile | 接收位置 服务方 内容类别 | 控制 MCP 内容输出 |
| PolicyRecord | 操作 范围 三态 依据 有效期 | 控制具体操作 |

| SourceObservation | 字段值 来源 时间 核验状态 | 保留冲突和历史观测 |
| DigitalAsset | 哈希 格式 路径 取得依据 | 关联发表版本且不可变 |

一个 ResearchWork 可包含多个 PublicationVersion；一个版本可有多个 DigitalAsset；一个文件可有多个 ParseArtifact；证据固定引用具体解析产物。更换文件、解析器或正式版本时生成新记录，已有证据保持原绑定。公开 DOI、内部标识和文件哈希使用不同命名空间。

第二版可选综述模块拟补充研究计划、持久化文献卡、多来源论断、章节修订与语料快照，见第 19.8 节。上表描述基础实体，不表示这些扩展已经落库。

### 9.2 去重决策

同一来源稳定标识且无冲突的重复观测可合并。规范化 DOI 相同且书目信息一致时可自动匹配到同一发表版本。无 DOI 时，组合使用题名、作者、年份、刊会、卷页；近似匹配仅生成待核查候选。

DOI 或作者存在冲突时保留记录。预印本、录用稿与正式版可关联至研究集合，但保留版本差异。会议论文和扩展期刊论文使用 extends 关系，不默认删除一个；更正和撤稿通知单独保存并关联。文件哈希一致可避免重复保存，但同 DOI 下发生文件更新时保留新旧资产。

合并操作必须记录前后映射、来源字段和执行依据，支持回滚。筛选、引用和证据绑定发表版本；合并研究集合不能悄悄改变引用页码。

## 10 可选筛选与学科评价

### 10.1 两阶段输出

元数据阶段判断相关性、时间、类型、名单、引用和字段完整度。全文阶段判断方法与研究问题是否匹配，以及数据、实验或证明对结论的支持。输出相关性、方法评价、影响力和证据完整度四个独立维度，给出推荐阅读、条件纳入、待核查或按规则排除。

保留被排除记录及理由，允许用户撤销或覆盖。学术诚信风险以可核实线索呈现；系统不承诺自动判定论文真伪。刊会目录和引用量属于辅助信号，不能替代单篇内容判断。[S25]

### 10.2 起始配置

| 规则 | 起始设置 | 缺失和例外 |
| --- | --- | --- |
| 总开关 | 可完全关闭质量筛选 | 仍执行去重和来源标记 |
| 时间窗 | 默认不限 提供近五年预设 | 经典文献可人工保留 |
| 文献类型 | 用户选择 | 综述 理论和学位论文分别评价 |
| 刊会名单 | 默认软排序 | 严格模式可强制名单并记录版次 |
| 最低引用量 | 默认 0 | 新论文和未知引用不直接排除 |
| 相关性 | 首版采用解释标签和排序 | 数值阈值用标注集校准 |
| 撤稿状态 | 已确认撤稿默认不作论据 | 未命中记为尚未发现 |
| 全文评价 | 每适用维度 0 1 2 三级 | 未知影响覆盖率 不适用不计分 |
| 人工覆盖 | 始终可用 | 保存原结果和覆盖理由 |

探索模式侧重召回；平衡模式执行用户明确的范围约束；严格模式可要求名单和全文方法门槛。原始引用量按数据来源和时间分别记录，不相加；跨学科阈值分别设置。有可靠完整比较群体时才使用同领域同年份百分位，不能用少量检索结果冒充全领域分布。

### 10.3 方法评价和覆盖率

每个适用维度取 0 为缺乏支持，1 为部分支持，2 为证据充分。未知项不当作 0；不适用项从分母移除。证据覆盖率为已完成且有依据的适用项数除以全部适用项数。必须同时显示分项结果、证据定位、未知项和覆盖率。

严格模式的可选起始门槛为已评价适用项平均分不低于 1.5、全部适用核心项均已完成有证据的评价且无 0、证据覆盖率不低于 80%。任一适用核心项未知则进入待核查；核心项判为不适用需给出依据。这些只是试点规则建议，不能解释为学界通用标准或质量概率。先使用标注集调节，再使用独立验收集测量误杀与遗漏。

### 10.4 学科模板

| 模板 | 重点评价证据 | 适用限制 |
| --- | --- | --- |
| 经管实证 | 数据来源 样本选择 变量 识别假设 内生性 稳健性 | 因果结论需要相应识别依据 |
| 计算机算法与系统 | 数据划分 泄漏 基线 消融 随机性 算力 复现条件 | 按实际研究类型选择适用项 |
| 电气和电子信息 | 仿真与实测 工况 参数 测量误差 基准比较 | 仿真结果不能表述为工程实测 |
| 实验理科 | 对照 校准 重复 不确定度 数据支持 | 样本量门槛按研究设计设置 |
| 理论与数学 | 定义 假设 证明 引理 适用条件 | 不强制实验 数据集或代码 |

名单记录体系、版次、年份和来源。CSSCI、北大核心、EI、SCIE、CCF、CORE、JCR 与中科院分区分开管理；商业名单由用户或机构在许可范围内提供。没有开源代码、短篇幅或低引用不能作为跨学科统一淘汰理由。

## 11 全文处理与证据综述

### 11.1 全文获取

下载请求显式传入 session_id，并核对其学校与项目绑定一致，禁止自动选用最近登录会话。下载前依次核验操作许可、会话状态和单篇资源访问。使用同一授权浏览器上下文完成正常下载，避免将一次性链接和 cookie 暴露给 Agent。保存取得来源、时间、权限依据和对应发表版本。

下载成功必须满足文件已落盘、大小和文件签名合理、可被格式检查器打开且文件哈希已记录。将登录 HTML、错误页或不完整文件当作失败；不能以点击按钮或出现下载链接为成功。未订购资源保留题录，并可提示学校正常文献传递渠道。

PDF 为首版主要阅读格式。CAJ 保留文件及状态，允许用户提供合法 PDF 或人工笔记；不把 CAJ 转换作为首版闭环的必需依赖。HTML 全文如有合法稳定接口可后续扩展，保留章节锚点而不伪造页码。

### 11.2 解析与片段检索

先检查文本层与阅读顺序。文本 PDF 采用轻量解析，扫描或复杂版面按需路由 OCR 或 MinerU。每次解析保存解析器名称、版本、参数和质量标记。表格数值保留单位、表头和页码，公式无法可靠解析时返回图像位置或人工复核状态。

页定位同时保存从 1 开始的 PDF 页序号与印刷页码，印刷页码缺失时为空。保留章节、块标识和必要坐标。片段检索支持关键词和可选多语种语义检索；返回证据标识、正文片段、上下文和定位，不默认把整篇论文塞入模型上下文。

### 11.3 综述生成与检查

本节规定用户明确选择综述任务后的基础处理要求，综述不作为其他文献操作的必经步骤。第二版可选模块的开关、阅读覆盖、文献卡、跨文献综合和增量修订方案见第 19 节；本次文档修订不改变现有基础工具的运行行为。

先建立文献矩阵，再按研究问题生成正文。每项研究事实关联发表版本、资产哈希、解析版本和证据片段。方法评价引用全文依据；数字结论返回原段落及表格上下文；因果判断保留研究设计条件。

每条记录标记 metadata_only、abstract_only 或 fulltext。只有摘要时允许主题归类和摘要级比较，方法细节及强度标明未核验。跨论文综合判断显式说明综合依据；冲突结果、研究条件和局限保留在综述中。

上述层级表示可用材料层级，不证明 Agent 已完整阅读或理解全文。第二版另行记录实际返回的页或章节、结构化抽取进度及人工核查状态，不把解析成功等同于阅读完成。

检查分为身份检查和支持检查。身份检查确保引用标识确实存在且对应实际版本；支持检查核对证据是否支持论断。确定性检查、模型辅助检查和人工抽检分别记录。证据不足时输出待核查内容，不能补造页码、作者、DOI 或原文。

参考文献默认支持 GB/T 7714—2025，保留学校指定的 GB/T 7714—2015。记录具体 CSL 样式标识、版本和获取日期，通过黄金样例确认实现，不能仅修改样式名称。[S26][S24]

## 12 MCP 接口契约

表内除标明 P1 的 Zotero 同步外均属于首版基础接口交付范围，不要求每个项目调用全部接口；prepare_review、save_review 由用户按需请求。项目和规则通过 MCP 创建；人工覆盖、重复确认及合并回滚通过相应工具操作，不要求用户直接修改数据库。学校档案和客户端处理档案通过本地配置管理，变更时校验并记录版本。

所有工具和资源统一执行内容出站策略。read_paper 未指定文件与解析产物时，按项目锁定配置选择并明确返回 asset_id、文件哈希及 parse_artifact_id；历史综述和证据重放必须使用原快照。get_paper 默认只读本地数据，只有显式请求刷新且提供有效会话时才联网。

save_review 保存的是可复核草稿；首版通过 Agent 撰写，不默认在 MCP 内重复调用另一个生成模型。P0 提供文献矩阵、证据包、草稿保存与引用检查的基础接口，用户明确请求后使用，不要求普通文献任务生成综述。第 19 节的第二版扩展接口及项目级开关尚待实现，不计入现有工具数量。

### 12.3 初始工程保护值

检索每次最多返回 20 条、单次研究任务初始候选预算 100 条、片段读取初始上限约 6000 字符、top_k 初始不超过 10。单文件导入初始限制 50 MB 和 200 页，超限返回可解释状态并允许经配置调整。用户可以调低；调高需受来源、许可和运行配置约束。这些是本地响应和成本保护值，不是知网官方额度或允许抓取的数量。

项目仅允许访问已配置来源、项目数据目录与用户明确选定的导入文件。客户端为云端环境时，不能假定能直接连接本地 stdio 服务；远程桥接和多用户认证作为后续独立设计。

## 13 运行部署和任务恢复

### 13.1 首版模块目录

| 逻辑目录 | 保存内容 |
| --- | --- |
| app 与 mcp | 启动 编排 工具和资源契约 |
| access 与 providers | 两模式接入 学校识别和知网适配 |
| domain 与 storage | 实体 版本 数据库与迁移 |
| screening 与 citations | 规则 学科模板 引文导出 |
| parsing 与 evidence | 解析器 片段索引 证据与综述检查 |
| jobs 与 observability | 任务 状态 恢复 日志与诊断 |
| tests 与 fixtures | 单元 契约 脱敏页面和人工黄金样本 |

这些是实施阶段的目录职责建议，当前文档交付不创建项目程序。运行数据默认放在用户选择的本地数据根目录，数据库、原始文件、解析产物、导出和诊断分开存储；身份会话与文献正文隔离。

### 13.2 并发与状态

同一浏览器上下文由会话管理器串行调度，防止检索翻页与下载操作相互干扰。下载按机构许可控制并发和间隔；解析可独立排队。首版采用 SQLite 持久任务和本地工作进程，不必同时引入消息队列服务。

任务状态为 queued、running、waiting_for_user、succeeded、partially_succeeded、failed、cancelled。记录完成项、失败项和安全检查点。退出或崩溃后，运行中的任务转为待恢复，不自行重放有外部副作用的操作。

幂等键由用户请求、文献版本、操作和配置摘要构成。文件已完整存在时复用；不完整临时文件不标为成功。取消后停止调度新增项，已完成结果保留。重复取消、状态查询和恢复请求应有确定结果。

### 13.3 日志和模型调用

日志保存 request_id、job_id、阶段、脱敏来源、耗时和错误码。禁记密码、cookie、验证码、Authorization、SAML、完整登录回调和未脱敏登录截图。诊断默认使用脱敏文本，截图只按用户选择保存到本地受控目录。

文献正文和网页内容作为外部数据处理，不能执行其中的工具调用指令。服务只开放专用文献操作，不开放任意浏览器脚本、任意网络请求或 shell。模型策略记录允许的提供方、可发送内容类别和预算；身份数据始终不进入模型调用。

### 13.4 数据维护

数据库迁移按版本执行，升级前备份数据库及必要清单。资产不可变，删除项目或文件先展示影响范围，并保留可恢复策略。缓存按字段更新频率和许可要求设置；引用量、访问状态和许可到期需要重新检查。重建索引不覆盖原始文件与历史证据。

## 14 实施计划和里程碑

排期按单人、单校、本地试用版估计 8 至 10 周，外部授权和学校协调等待时间另计。真实接入验证、元数据闭环和证据综述分别设里程碑，避免离线演示掩盖在线能力缺口。

| 阶段 | 时间 | 必须交付 | 退出条件 |
| --- | --- | --- | --- |
| M0 接入验证 | 第 1 周 | 学校档案 两模式验证 操作许可表 40 篇抽样 | 明确可自动化范围及未获准能力 |
| M1 检索闭环 | 第 2 至 3 周 | MCP 会话 检索 分页 详情 本地库 | 真实入口完成固定检索用例 |
| M2 文献整理 | 第 4 至 6 周 | 版本去重 规则筛选 引文 导入导出 | 可解释结果和黄金样例通过 |
| M3 阅读与可选综述 | 第 7 至 8 周 | 授权全文 解析 证据；提供按需调用的矩阵和草稿接口 | 全文证据可定位；选择综述的测试任务验证论断定位和恢复 |
| M4 试点验收 | 第 9 至 10 周 | 独立验收 缺陷修复 安装和用户文档 | 关键缺陷关闭并报告实际能力 |

M0 未取得在线操作条件时，明确调整接入路线，并继续开发导入后的整理和阅读功能。该调整必须反映在里程碑状态和交付声明中，不能将导入成功标记为在线搜索或下载通过。

P0 为两模式接入、可追溯题录、确定性去重、规则开关、引文、文本 PDF 证据、可按需调用的文献矩阵及 Agent 综述草稿保存检查接口与任务恢复。P0 表示开发交付范围，不表示用户必须启用综述流程。P1 为外部元数据增强、语义重排、Zotero 同步和复杂 OCR。P1 不影响 P0 接口与数据关系；未启用时验收其正确降级，扫描件与复杂版面解析质量目标仅在相应组件启用后适用。

第二版增强综述模块属于用户可选扩展，按第 19.9 节独立推进，不纳入上述首版 8 至 10 周排期，也不以其启用作为基础文献功能的交付条件。

## 15 验收集和通过标准

### 15.1 样本与方法

M0 从经管、计算机、电气或电子信息、理科各抽取约 10 篇，共 40 篇，检查元数据、摘要、PDF 与 CAJ 比例、入口差异和权限。后续准备约 100 篇分层试标注样本用于规则调节，另留至少 50 篇独立样本作最终验收；包含新论文、经典论文、无 DOI、扫描件、公式表格、缺失字段和版本关系。

另备 20 个固定检索问题、50 组重复或相关版本样例、50 个引文黄金样例；综述能力验收任务启用时，另备至少 100 条综述事实。未选择综述的普通任务不要求提供该类产物，未测的综述质量不能记为通过。独立筛选验收集按五类模板各至少 10 篇分层，每类含至少 5 篇专家认为应纳入的正例；达不到此条件时补样或明确该模板未完成验证。规则、提示词和模型版本在验收前冻结。

领域复核者给出纳入意见和依据；有条件时两人独立标注并记录分歧。样本规模用于发现缺陷和估计表现，不能据此宣称所有学科已达到统一准确率。

### 15.2 认证与访问用例

| 用例 | 场景 | 通过条件 |
| --- | --- | --- |
| AUTH 01 | 校内网直接访问 | 正确识别目标机构并记录依据 |
| AUTH 02 | 用户先连接学校 VPN | 同模式完成验证 项目未管理 VPN 凭据 |
| AUTH 03 | 普通外网首页可达 | 无机构证据时不报 ready |
| AUTH 04 | CARSI 正常认证 | 用户完成后返回知网并核验学校 |
| AUTH 05 | CARSI 扫码 MFA 验证码 | 等待用户 凭据和断言无泄露 |
| AUTH 06 | 实际机构不符 | 返回不符状态并暂停目标学校任务 |
| AUTH 07 | 已登录但论文未订购 | 保留题录 不尝试未经允许的获取 |
| AUTH 08 | 自动下载许可未知或拒绝 | 返回许可状态 可人工导入 |
| AUTH 09 | 会话在任务中失效 | 停止新增请求 重认后安全恢复 |
| AUTH 10 | 来源提示访问频繁 | 暂停且不自动切换身份或路径 |
| AUTH 11 | 学校或模式切换 | 旧新上下文和许可无串用 |
| AUTH 12 | 既有 WebVPN 不兼容 | 返回兼容性限制 无第三模式承诺 |
| AUTH 13 | 清除会话后重启 | 已清除状态不再被复用 |
| AUTH 14 | 审查输出和日志 | 无密码 cookie 验证码或身份断言 |

两种认证模式需要在试点学校真实验证。学校不支持其中一种时，记录该模式未通过试点验收，并选择能同时验证两种模式的补充试点或调整验收范围；不能将模拟 IdP 当作真实学校成功结果。

### 15.3 功能和质量验收

| 需求 | 样例和目标 | 判定方式 |
| --- | --- | --- |
| POL 01 | 操作许可三态和范围均可追溯 | 未知或拒绝能力不被下游调用 |
| SEA 01 | 20 个固定问题与人工页面对照 | 页条件 计数 截断原因完整 关键路径无未解释失败 |
| MET 01 | 核心题录字段准确率目标不低于 95% | 按字段 学科和缺失状态分别报告 |
| DED 01 | 50 组关系样例关键误合并为 0 | 自动合并精确率目标不低于 99% 候选可回滚 |
| QUA 01 | 独立集应纳入文献召回率目标不低于 95% | 同时报告误杀 原因 分层数量及不确定性 |
| CIT 01 | 50 个黄金样例 | 必需字段与格式逐项核验 虚构字段为 0 |
| FUL 01 | 正常 失败 过期和重复请求 | 成功文件可验证 可追溯 幂等且不误报 |
| PAR 01 | 文本 扫描和复杂版面分层抽检 | 页序号定位目标不低于 95% 解析缺陷单列 |
| REV 01（综述能力验收） | 显式选择综述的测试任务至少 100 条事实抽检 | 支持率目标不低于 95% 虚构论文和证据为 0；未测不记通过 |
| JOB 01 | 断网 取消 崩溃 单文件失败 | 已完成结果保留 恢复不重复副作用 |
| SEC 01 | 会话 目录 模型出站和脱敏检查 | 关键泄露缺陷为 0 |

字段正确率按人工对照中已取得字段的正确数除以已取得字段数计算，字段可得率按实际采集到的字段数除以人工同会话可取得的字段数计算；两者与缺失率分别报告，人工页面本身缺失的值另行统计。去重精确率的分母为实际自动合并次数，筛选召回率的分母为独立集中专家认为应纳入的文献数，证据支持率的分母为本次抽检的实质性事实数。

解析测试至少包括 20 篇文本 PDF、10 篇扫描件和 10 篇含公式表格或双栏复杂版面的文件，可与前述文献样本复用。未启用 P1 时，扫描与复杂样本用于验证准确识别限制和降级，不能记为解析质量通过。

这些比例是建设目标，不是现有组件性能承诺。验收报告同时给出样本数、成功数、分层结果和失败案例；小样本去重精确率应按实际计数解释。任一越权操作、凭据泄露、关键误合并或虚构证据属于阻断缺陷。其他 P0 目标未达成时，该项不得记为通过；如发布受限试用，需记录项目负责人的例外决定、适用范围和修复计划。

第二版可选模块另按第 19.10 节验收启用、关闭和恢复行为。关闭状态必须验证基础功能独立可用；仅验证关闭行为不等于综述质量验收通过。选择对外宣称综述能力时，仍须执行对应质量验收，不能以“可选”为由跳过后宣称达标。

### 15.4 性能和资源口径

M0 冻结测试电脑、网络路径、文件规模、模型、解析器和并发配置。对本地状态查询与本地题录读取各重复至少 30 次，记录中位数和 P95，初始目标为 P95 不超过 1 秒；长任务受理初始目标为 2 秒内返回 job_id。真实检索、下载、解析和模型调用分别记录耗时、失败率与峰值内存，不用模拟耗时替代真实来源结果。

初始网络单请求超时 30 秒、单文件解析 300 秒、单次模型调用 90 秒，均可在 M0 按实测调整后冻结。等待用户认证使用独立状态，不在后台无限运行或持续模型轮询。超时后保留可恢复记录；大文件、低配设备及未启用 OCR 的能力边界在验收报告中列明。

## 16 风险与决策记录

| 风险 | 触发信号 | 对策和交付影响 |
| --- | --- | --- |
| 自动化许可不足 | 条款禁止或许可未知 | 关闭对应操作 在线功能保持未验收 |
| 页面和入口变化 | 机构识别或字段抽取异常 | 停止采集 脱敏夹具回归 修正适配器 |
| CARSI 学校差异 | 无目标学校或跳转异常 | 更新档案 用户交互 必要时补充试点 |
| 网页代理不兼容 | 域名重写或下载失败 | 返回限制 使用已支持路径 |
| 中文和扫描解析差 | 阅读顺序 公式 表格失真 | 分层路由 人工复核 不生成强结论 |
| 指标覆盖不足 | 无 DOI 引用或名单匹配 | 缺失状态与覆盖率独立呈现 |
| 模型生成无依据 | 引用不存在或片段不支持 | 身份检查 支持检查与人工抽检 |
| 任务范围过大 | 多校 多租户或复杂格式挤占排期 | 保持 P0 范围 将扩展列入后续 |

开工时确认试点学校、官方指南和入口、用户身份资格、两模式支持情况、自动化与内容处理许可、模型运行位置、学校引文模板及领域复核者。每项决策记录日期、依据、负责人角色、影响范围和复查条件。当前学校名称、接口合作条件和模型供应商保留为实施前待定项，不填造承诺或报价。

## 19 第二版可选文献综述辅助方案

### 19.1 目标与适用范围

本模块优先辅助毕业论文中的“文献综述／相关工作”章节。围绕一个真实课题，积累可核查的阅读成果，比较研究路线、结论与条件，形成可持续修订的一章综述。系统综述、范围综述和元分析涉及额外的方法要求，后续独立设计，不因生成矩阵或检索流程图就宣称完成。

用户启用后，可按需取得研究计划、文献卡、主题比较矩阵、章节提纲、分节草稿、论断核查清单和格式化参考文献。Agent 负责理解与写作，MCP 负责材料、状态、证据和版本持久化；继续使用现有本地单用户架构。

本节为第二版建设方案。现有基础矩阵、草稿保存和引用身份检查，不等于已实现持久化文献卡、跨文献综合、语义支持核查或增量更新。

### 19.2 用户选择、默认状态与关闭行为

| 编号 | 选择规则 | 预期行为 |
| --- | --- | --- |
| REV2-OPT-01 | 默认关闭 | 拟在 ResearchProject 中增加 review_assistance_enabled，默认 false；旧项目缺少该字段时按关闭处理 |
| REV2-OPT-02 | 按项目自行选择 | 用户可通过明确指令或后续界面开关启用、关闭；选择仅作用于指定项目，不自动扩展到其他项目 |
| REV2-OPT-03 | 明确选择后保持 | 启用状态持久化；换聊天或服务重启后读取既有选择，不要求用户逐篇、逐节重复启用 |
| REV2-OPT-04 | 关闭时独立使用基础功能 | 检索、导入、去重、可选筛选、全文获取与单篇阅读、证据查找及参考文献导出继续独立使用 |
| REV2-OPT-05 | 关闭时停止自动编排 | 不自动新建综述阅读卡、主题比较、章节草稿和支持核查任务，也不因导入论文或研究问题含“综述”二字而自动启用 |
| REV2-OPT-06 | 关闭不删除成果 | 已有文献卡、草稿、历史核查与版本保留，可依许可查看或导出；关闭不撤销共享的基础下载和解析任务 |
| REV2-OPT-07 | 处理中关闭 | 停止新增综述工作，在安全检查点结束当前综述任务并保存进度，不留下半条记录；再次启用后显式恢复，避免自动重放 |
| REV2-OPT-08 | 开关与其他设置独立 | 启用综述不强制开启质量筛选、OCR、语义检索、其他来源接入或外部模型服务；也不代替来源和内容处理许可 |
| REV2-OPT-09 | 能力尚未交付 | 请求未实现的扩展时返回明确未启用或不可用状态及已有替代路径，不以空矩阵冒充综述完成 |

拟新增开关控制的是第二版增强综述工作流。本次修订不改写现有 prepare_review、save_review 等基础接口的实际调用行为；实现时须明确基础显式调用与增强工作流的边界，保证注册基础接口不产生隐式启用。扩展写入和编排入口校验项目选择，历史只读与导出仍遵守统一出站策略。

启用功能不意味着立即联网、下载全文或一次性生成整章。实际执行范围以用户任务、已保存研究计划、预算、许可和材料情况共同决定；用户可以只完成文献卡或主题比较后结束。

### 19.3 研究任务与检索计划

保存可修订的研究计划：毕业设计目标、学科、综述子问题、研究范围、时间与语言范围、文献类型、纳入排除标准、种子文献、章节要求及用户指定格式。用户调整范围时生成新版本，并说明对已有筛选和阅读成果的影响。

围绕子问题组织关键词、同义词和中英文术语，保存计划查询与实际执行查询的对应关系。按来源已核验能力生成受控检索，不把尚不支持的布尔表达式、年份或类型控件当作可执行条件。记录来源、日期、过滤模式、排序、实际页数、采集数、去重数和预算截断原因；可借鉴 PRISMA-S 的报告字段。[S27]

将相关性与期刊名单、引用量和方法评价分开。纳入文献可标记为核心依据、直接相关、背景资料或待判断，并记录与子问题的关系。其他来源文献先沿用合法 RIS、BibTeX、CSL JSON 与 PDF 导入，保留取得来源，不将知网候选集合描述为全部国内外研究。

### 19.4 持久化文献卡与阅读进度

每篇文献形成可保存、纠正和复用的结构化文献卡，先支持文本型 PDF，按材料情况补充摘要级卡片。

| 字段组 | 内容与约束 |
| --- | --- |
| 研究问题与贡献 | 作者具体解决的问题、主要贡献及适用范围 |
| 方法与设计 | 理论、算法、识别策略、实验或证明路径；缺失时保持未知 |
| 数据与条件 | 样本、数据集、工况、比较对象、指标、单位及必要上下文 |
| 主要发现 | 结论及成立条件，关键数值能够回查原段落或表格上下文 |
| 局限与关系 | 分开保存作者承认的局限、Agent 分析、用户判断及与毕业设计的关联 |
| 字段级证据 | 关键事实绑定 version_id、asset_id、parse_artifact_id、文件哈希、证据标识及 PDF 页序号 |
| 版本与核查 | 修改者角色、修改时间、变更原因、待核查项和用户修正记录 |

原文陈述、Agent 解释和用户判断分别标记来源；Agent 推断不能伪装为作者原话。只有摘要时可提取摘要实际包含的信息，方法细节和强度判断保留未核验状态。表格、公式和阅读顺序不可靠时保留质量提示，不补造数值、单位或页码。

分别记录四类状态：材料是否取得及可解析、实际返回给 Agent 的页或章节、结构化字段是否完成、哪些内容已经人工核查。返回阅读范围是操作记录，不能据此声称模型理解；metadata_only／abstract_only／fulltext 继续只表达可用材料层级。

文献卡按研究子问题关联，复用已有合适快照和阅读成果。更换课题范围或修正文献卡时保留旧版本，避免每次 prepare_review 都丢弃已完成分析并重新填空。

### 19.5 按问题获取证据与统一快照

根据子问题、文献卡缺口和拟写章节选择证据，支持按文献、章节、阅读层级和解析快照过滤，返回前后文或相邻块。字符预算按任务和文献分配，显式提示未覆盖的文献、章节与下一步阅读请求；不以所有文献最前面的几个存储片段代替全文研究依据。

先改善中文查询、同义表达、章节定位与关键词召回，再用真实问题评估语义检索的增益。语义检索另行按用户选择与处理许可启用，记录组件和嵌入版本；不能只用相关度分数证明证据足够。

项目语料快照显式列出选定发表版本、文件和解析产物。文献卡、证据搜索、主题比较与草稿默认使用同一份选定快照；历史快照可显式读取，重解析不自动更换旧引用。相邻重叠片段去重展示，不同版本和同一研究的重复报告不能自动计为多份独立支持。

### 19.6 主题比较与跨文献综合

围绕研究子问题形成用户可编辑的主题及比较矩阵，比较方法路线、数据与假设、指标、结果、适用条件和局限。保留共识、分歧、反证及可能解释，对条件不同、不能直接比较的结果明确标记。

一条综合论断拥有独立 claim_id，可通过多个来源关系同时关联不同论文；关系记录支持、反驳、限定条件或背景作用。单篇发现与“多数研究”“结果不一致”“存在研究空白”等综合判断分别处理，必要时标记共同数据或研究关系，避免重复计算支持。

研究空白保存推理依据及检索范围。优先描述“本项目当前纳入文献中发现的不足”，并给出待补检索或待核查项；不能仅凭少量候选、自动聚类或未检索到某个词，断言尚无人研究。主题与毕业设计的关联由用户和 Agent 分别记录，不把分类标签直接当成创新性证明。

### 19.7 分章节写作与论断核查

每节先保存要回答的问题、核心论点、支持与相反证据、缺口和写作范围，再由调用方 Agent 撰写。优先完成一小节供用户修改，逐步扩展整章；保留人工修改及其来源，不因重新生成其他部分而覆盖。

正文段落、论断和证据使用稳定内部标识关联。写作改动后重新检查受影响论断；更改了论断含义的人工编辑同样不能沿用旧的“已核查”标记。

| 核查层 | 处理范围 | 输出 |
| --- | --- | --- |
| 确定性检查 | 文献身份、证据存在与归属、快照一致、引用与书目对应、原文引语 | 可定位错误、缺失关联及待处理项 |
| 模型辅助支持核查 | 论断与上下文是否相符、数值单位、适用条件、因果表述、比较及反证 | 充分支持、部分支持、矛盾、证据不足或未判断，并附理由与证据 |
| 人工核查 | 核心结论、重要数字、研究空白及模型提出的问题 | 用户判断、修订记录和核查状态 |

另行识别正文中尚未提交证据映射的事实性句子，形成待核查队列；不能只检查调用方已经提供的 claims 后宣称全文事实覆盖完成。数字与单位需核对上下文，不因同一数值出现过就判为正确。模型辅助意见与人工判断分开保存，不将模型自评视为语义认证。

### 19.8 数据、接口、恢复与导出设计

继续使用 SQLite 与现有作品、发表版本、文件、解析和证据关系，拟增加以下实体，不以引入独立图数据库或完整 Agent 调度服务作为前置条件。

| 拟新增实体 | 主要用途 |
| --- | --- |
| ReviewPlan | 保存研究子问题、范围、检索计划、纳排标准和修订关系 |
| CorpusSnapshot | 固定本次采用的发表版本、资产与解析快照清单 |
| PaperCard／ReadingProgress | 保存字段级阅读成果、返回范围、证据和核查状态 |
| SynthesisTheme | 保存主题、比较维度、分歧与关联文献 |
| ReviewClaim／ClaimSource | 表达一条论断与多个来源之间的支持、反驳、限定和背景关系 |
| ReviewSection／ReviewRevision | 保存稳定章节、父版本、正文、变更原因、人工修改与依赖 |

接口先围绕项目选择、阅读成果和可恢复进度设计。下表为拟议契约，命名和粒度在实现前确认，不是当前已注册工具清单。

| 拟新增或扩展入口 | 主要职责 |
| --- | --- |
| set_review_assistance | 显式设置项目开关，报告状态、适用范围及进行中任务的处理结果 |
| save_review_plan | 保存研究计划及修订版本 |
| save_paper_card | 保存文献卡与字段级证据，核验版本和快照归属 |
| get_review_progress | 读取开关、完成项、缺口、待核查项和下一步，不隐式开始任务 |
| prepare_synthesis | 根据子问题与文献卡准备主题比较及多来源论断材料 |
| 扩展 prepare_review／save_review | 支持选定语料快照、分章节、稳定论断与修订关系，保留基础调用兼容性 |
| get_review_impact | 分析新增论文、卡片修改或重解析影响的主题、论断与章节 |

任务状态和检查点落库，换会话后读取既有进度。用户关闭再启用时保留历史选择和成果，通过明确恢复操作继续，不重复下载、解析或覆盖正文。

新增论文、改动纳入标准、纠正文献卡或更换解析快照时，列出受影响章节与原因，生成局部修改建议和差异；修改被采用时保存新版本，旧草稿仍能回到原依据。核查状态随依赖变化失效，不能把旧审核结论直接复制给新论断。

导出综述正文、文献矩阵、引用清单、检索筛选记录、核查问题及运行版本信息。先支持便于检查的 Markdown／JSON，再按用户需求增加论文文档导出；正文显示编号与书目在导出时统一生成，内部引用身份保持稳定。文献卡中的摘要、全文派生分析、综述和导出继承来源处理限制，复用现有出站检查。

### 19.9 分阶段交付与后续能力

| 阶段 | 优先交付 | 退出条件 |
| --- | --- | --- |
| V2.1 阅读成果可积累 | 项目选择、研究计划、文献卡、阅读范围、上下文和统一快照 | 关闭状态基础功能独立可用；核心文献卡可回查原文、纠正并跨会话复用 |
| V2.2 形成综述章节 | 主题比较、多来源论断、分节草稿、核查队列和统一引用 | 一个真实课题先完成一节再扩展一章，关键判断有可检查依据，人工修改保留 |
| V2.3 支持持续修订 | 补检索建议、影响分析、版本比较、进度恢复和导出完善 | 加入新研究或修改阅读判断后，准确列出相关依赖并完成局部修订，旧版本可重放 |

每阶段以实际产物和失败案例推进，排期在试点材料及第一阶段测量后估算，不把首版排期直接复用为第二版承诺。用户可在任一阶段只使用已交付的部分能力，无需完成全部流程。

OCR、复杂表格和公式处理按核心文献的实际障碍安排；轻量查看界面在文献卡与证据关系稳定后增加。其他来源自动接入、Zotero 同步、独立模型服务及复杂调度后续按需求评估，均不成为启用综述辅助的隐含依赖。若扫描材料是核心依据，则明确阅读缺口并调整解析优先级，不能用未启用 OCR 的状态冒充已覆盖该文献。

### 19.10 可选行为与综述质量验收

选择一个真实毕业课题，以约 10 至 20 篇合法可处理的文本 PDF 开始试点，保留未参与规则与提示词调整的材料进行独立检查。该数量是工程起始规模，不是论文最低引用篇数或质量保证。冻结输入材料、快照和组件版本，对照现有版与第二版的阅读和写作产物，报告实际纠错及耗时。

| 用例组 | 关键检查 |
| --- | --- |
| OPT 默认与隔离 | 新旧项目默认关闭；对某项目启用不改变其他项目；研究问题或导入内容不隐式启用 |
| OPT 关闭与恢复 | 关闭时基础检索、导入、筛选、阅读和引文导出可用；无新增增强综述任务；处理中关闭保留完整检查点及成果 |
| OPT 选择独立 | 启用不强开筛选、OCR、语义检索或联网；重新启用后可恢复已有成果，不重复创建副作用 |
| CARD 阅读与抽取 | 关键字段能够回到同一快照原文；摘要级材料、未知字段、实际返回范围与人工核查状态准确 |
| SYN 综合判断 | 共识、分歧、研究条件及毕业设计关联能展开到多篇依据；重复版本不冒充独立研究 |
| CLAIM 支持核查 | 注入错误引用、数字单位差异、摘要补造方法、过度推广、相反证据和未映射事实，记录检出与漏检 |
| REVISION 变更影响 | 新增反对性研究、修正卡片、重解析和编辑论断后，受影响内容可识别，旧版本可查，过期核查状态不沿用 |
| EXPORT 引文与权限 | 删改及调序后正文与书目正确对应；缺失依据提示明确，受限内容不经卡片或导出绕过策略 |

验收分别报告字段事实纠正数、引用纠正数、关键证据定位成功与失败、支持核查检出和漏检、人工修改耗时及恢复结果，并附样本数和具体错误。关键事实和比较结论由人工对照原文，模型自评分不代替质量测量。对外宣称综述能力时仍遵守第 15 节相应质量验收要求；小样本试点通过只说明该范围内的结果。

第二版第一阶段的具体交付物为：用户可自行选择是否启用的一组持久化文献卡，能够纠正、追溯原文、恢复进度，并为后续跨论文比较提供一致依据。

## 20 文献检索与筛选增强方案（2026-10-20 补充，待实现）

### 20.1 目标与借鉴来源

将课题相关性、阅读优先级和方法质量分别保存。查询名次、模型相关性分数、期刊名单和引用量均不能替代论文纳入条件或原文方法评价。增强筛选独立于综述开关，沿用现有学校访问、许可、本地文献库、证据与任务边界。

| 借鉴来源 | 纳入方案的机制 | 在本项目中的位置 |
| --- | --- | --- |
| [CoLRev](https://github.com/CoLRev-Environment/colrev) | 题名摘要预筛、全文筛选、逐项标准和决定历史 | 增加版本化课题纳排协议与分阶段判断 |
| [RRF 原始论文](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf) | 根据多组结果的名次融合排序 | 在候选入库和保守去重后产生阅读优先级 |
| [FlagEmbedding](https://github.com/FlagOpen/FlagEmbedding) | 可选中文相关性重排 | 对已取得题名摘要或正文片段进行排序实验 |
| [PaperQA](https://github.com/Future-House/paper-qa) | 候选、证据准备、综合分离 | 针对每条标准准备可定位材料，再由调用方 Agent 判断 |
| [ASReview](https://github.com/asreview/asreview) | 标注反馈更新待筛顺序、模拟评测 | 候选规模扩大后提供题录和标签交换，按效果决定深度接入 |
| [PRISMA](https://www.prisma-statement.org/prisma-2020-flow-diagram) | 分阶段数量与排除原因报告 | 导出筛选流程清单；不将清单或流程图当作质量认证 |
| [GPT Researcher](https://github.com/assafelovic/gpt-researcher) | 子问题规划、按问题准备上下文、分节研究与修订 | 借鉴编排思路，继续由现有 Codex 调用；不增加隐含模型服务 |

完整工具链不是首批依赖。优先实现可解释的筛选契约，再在独立样本上验证排序、重排和主动学习的增益。

### 20.2 多组查询、候选覆盖与排序

保存概念组、同义词、字段、查询目标和每组预算。当前知网入口尚未核验复杂布尔 DSL，概念组合必须编译为现有适配器实际支持的受控查询，不将写出的 AND/OR 表达式当作来源已执行条件。

同一项目总预算内为多组查询预留额度；在线操作仍按既有会话锁、访问间隔和许可串行执行。逐次记录 query_id、来源稳定标识、来源名次、字段、排序、页码、获取时间、预算截断和停止原因。重复命中保留查询关联，不重复计为独立论文。

可试验 RRF：`score(d) = Σ 1 / (k + rank_i(d))`，只对文献实际出现的列表求和。列表内先去重，相同查询不重复投票；k=60 仅作为原论文提供的实验起点。候选合并与排序不得自动排除低分文献，也不得把分数解释为质量或纳入概率。

可选中文重排后端记录输入材料快照、模型版本、参数、截断范围及回退方法。无摘要者保留补材料状态，不因输入短而自动排除。先与当前字面检索及查询并集比较，再决定是否启用。

### 20.3 逐项纳排协议与两阶段筛选

标准保存稳定 criterion_id、协议修订、具体定义、适用阶段、是否必需、证据要求及正反例。按学科与实际研究类型配置对象、问题、情境和研究设计，不强制统一套用医学框架。

每篇文献、每条标准保存 `meets / violates / unknown / not_applicable`、理由、阅读层级、摘要 observation_id 或全文 evidence_ids、原文引语和判断来源。不适用需有理由与依据，不能绕过协议中的必需条件。Agent 与用户声明分别记录，调用方角色不等于身份认证。

| 阶段 | 判定规则 | 后续处理 |
| --- | --- | --- |
| 题名摘要预筛 | 明确违反该阶段可判定的必需条件 | 保留排除决定与原始材料；仍可人工覆盖 |
| 题名摘要预筛 | 当前阶段条件满足 | 进入全文阶段，不直接声称最终纳入 |
| 任一阶段 | 关键材料未知、摘要截断、存在证据冲突 | 补材料或待复核；缺少描述不等于明确不符合 |
| 全文核验 | 所有适用必需条件已有符合依据，且无未决冲突 | 纳入选定用途；方法质量另行评价 |

若存在有证据的明确违反和其他未知项，保存两者，以明确违反作为排除依据。背景材料、反证及不满足核心论据条件的论文仍可留在本地库并注明用途，不因筛选而物理删除。

服务核验项目与发表版本归属、冻结材料快照、证据存在、引语子串和所需处理许可。语义判断由调用方 Agent 或用户提交；这些确定性检查不认证判断正确。

### 20.4 证据准备、方法量规与上下文预算

针对单条标准或方法维度提出问题，先检索与阅读支持、反驳及限定条件，再保存判断。沿用原始片段定位与完整上下文入口，记录未命中、截断、解析缺陷及尚未读取范围，不能只保存 Agent 摘要而丢失原文关系。

0—2 分量规需逐项定义可观察条件、例子、未知与不适用情形，并保存 rubric_version。相关性排序、课题资格和方法质量分开，不以高相关性补偿方法缺陷。

当前严格模式在没有缺失项时才检查覆盖率。实现增强时，需明确区分核心与补充维度并测试缺失策略，或明确要求全部适用项完成；不得声称现有 80% 阈值已实现允许部分未知时的独立放行。

借鉴 GPT Researcher 的按问题选择上下文与关键词回退思路，但针对中文适配分词或字符粒度，并使用当前证据检索作为基线。有用性等级用于材料优先级，不直接等同于论文质量。新增外部筛选后端需明确内容处理方及许可；不默认引入其 API 或将网页报告的效果推广为中文论文筛选效果。

### 20.5 主动学习、停止建议与流程统计

先提供与 ASReview 的题录、标签和稳定标识交换及回导验证，规模与效果支持后再评估嵌入。人工核验标签与 Agent 标签分开；同一 Agent 多次判断不当作独立人工评审。

连续不相关数量、模型排序或采集预算可作为停止原因或提示，不能作为已经找全的证明。保留未筛集合、抽查范围和漏检记录；明确区分来源末页、候选预算耗尽与质量目标达成。

流程统计按阶段和唯一发表版本汇总，同时保留检索记录、报告与实际研究之间的对应关系。关系未知时明确标注，同一研究的多篇报告不冒充独立研究。报告排除主因与其他命中原因、人工和 Agent 决定、待复核数量及历史覆盖；多条规则命中不能重复扩大论文排除总数。

### 20.6 接口、兼容性与交付顺序

| 拟议入口 | 职责 |
| --- | --- |
| save_selection_protocol | 保存协议、阶段、证据要求及查询计划的不可变修订 |
| save_selection_assessment | 保存逐项判断并产生可解释的汇总决定 |
| get_screening_queue | 返回缺材料、未处理、冲突与待复核项，可选优先级 |
| export_selection_flow | 导出阶段统计、排除理由、未决集合、判断来源和历史 |

以上名称为方案，不是当前注册工具。单查询 search_papers 保持兼容，多查询首版由 Codex 编排。旧 policy、decision、override 保留；修改标准产生新协议修订并标记受影响判断需复核。数据库索引、项目隔离、迁移备份及导出权限随实现校验，筛选不依赖启用增强综述。

| 批次 | 交付内容 | 退出条件 |
| --- | --- | --- |
| 第一批 | 协议、逐项证据、摘要与全文阶段、队列、历史及流程统计 | 无依据排除、未知误判、串用证据、阶段误报和统计重复等用例通过；使用真实材料核对决定 |
| 第二批 | 查询预算分配、名次记录、RRF 和可选中文重排 | 同预算比较单查询、查询并集和重排；报告排序效果与候选获取效果 |
| 第三批 | 主动学习交换、模拟与停止建议 | 独立全标注集合中测量召回、工作量与漏检，保留未决状态 |

### 20.7 独立评测与验收边界

沿用第 15 节分层样本与独立验收要求。开发调参与验收集合分离；相同研究、不同版本和近重复文本按组划分，避免信息泄漏。冻结材料、协议、量规、模型及提示词版本，分别评价候选获取、相关性排序、纳排判定和方法评价。

报告前 K 条相关比例、标注候选集内 Recall@K、最终纳入精确率与召回率、错误排除、待复核率、人工分歧、证据定位失败和实际耗时。待复核单列，不自动计为正确纳入。没有明确参考集合时不报告全库召回率，模型自评分不代替人工金标准。

新增工程能力和上游基准均不能将本项目的 95% 召回率建设目标改记为已达成。真实验收完成前，在说明和导出中保持待验证状态。实现细节与来源追踪继续维护于[融合调研](文献检索与筛选融合调研.md)。
