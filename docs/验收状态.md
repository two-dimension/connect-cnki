# 验收状态

日期：2026 年 10 月 19 日。此文区分软件实现、人工夹具测试和真实厦大接入，不以夹具结果代替在线能力。

## 当前交付

39 个 MCP 工具、3 个资源和 3 个工作流提示已实现。本地安装脚本、项目级 Codex 注册脚本、厦大初始档案、固定依赖和第三方样式来源清单已提供。`config.local.json` 与 `.codex/config.toml` 由脚本生成并忽略 Git；标准配置默认 Edge 临时独立上下文，接收方为 OpenAI，初始仅输出题录。

用户已确认试点学校为厦门大学、电脑已连接校内网，并进一步明确许可适用于全部非商业个人科研用途。本机据此记录用户确认依据，启用检索、题录采集、全文下载、本地解析及 OpenAI 内容处理；用途被约束为 `personal_noncommercial_research`。用户没有指定到期日，保存为空值，不编造截止日期。该配置记录用户的许可说明，未将其伪装为独立核验过的学校文书；其他新档案仍默认未知。

## 自动验证

当前共 70 个测试，覆盖：

- 精确主机、URL 脱敏、未知/拒绝许可与模型服务方范围。
- 用户确认的非商业个人科研用途匹配、未指定到期日保持空值、其他用途拒绝，以及文档型许可仍要求有效期。
- 静态 CDN 只放行指定资源类型，拒绝其导航和数据请求；配置重载保留专用上下文及人工验证会话，并要求重新核验机构。
- CDP 逐跳阻止原生 302 导航越界；原生 302 的已知 HTTP 返回只生成本地 HTTPS 导航。已核验认证 GET 路径可作相同修正，POST 与其他回调仍拒绝。
- 保守 DOI 去重、作者冲突保留、合并回滚、筛选关闭、人工覆盖与严格模式未知项。
- PDF 签名与结构校验、允许目录边界、解析子进程、证据页序号、文件哈希及历史快照。
- 扫描页没有文本时降级为待 OCR，任务只报部分完成，读取不标为已读全文。
- 摘要、正文、矩阵、评分理由、草稿、MCP 资源和项目导出的内容出站检查。
- 幂等键冲突、取消、重启恢复、单数据目录实例互斥。
- 版本 1／2 到 3 的一致性备份与哈希清单、题录及外键关系保留、迁移失败完整回滚、较新 schema 拒绝和锁释放；工具与任务阶段的脱敏耗时审计。
- 检索与题录采集取较低数量额度和较长间隔，跨查询保留项目上限，解析器不提取超出剩余额度的结果行。
- 显式本地候选筛选保留年份未知、年份不符和类型不符的排除理由；模式绑定游标，类型受限许可在联网前拒绝此替代路径。
- 校验失败的下载保留未验证文件及固定类别清单，未注册为资产或成功全文。重复字典键的专用兼容路径保持原文件不变，返回需结构复核与部分完成；缺少结束标记的文件仍拒绝。
- 来源页因额度截断时明确标记，已有重复文献使项目尚未满额也不能跳过未采集的页尾；实际提交查询后重新记录间隔起点。
- 默认排序未知时在联网前拒绝请求；显式排序等待结果节点更新，并核验来源的激活控件，包含排序前后文字相同但节点已重建的情况。
- 新窗口下载 PDF 与原生重定向后下载 PDF 的任务入库；隐藏同名按钮不参与选择，新窗口首跳先生成本地导航文档，再安装逐跳检查。新窗口 302 越界仍在联网前拒绝。
- **真实 stdio 子进程**：initialize、tools/list、tools/call、structuredContent、资源读取和 schema 错误。
- **真实 Edge 浏览器配合人工 HTML**：精确机构识别、同页缓存分页、异步翻页、游标重复消费、机构不符和安全验证状态。网络请求由夹具拦截，没有把夹具称作知网。
- 同一上下文中另一个来源页出现安全验证时，既有机构标签不能覆盖待交互状态；布局诊断不返回检索输入框的实际值。
- 新版结果行 `data-dbname / data-filename` 提供稳定身份；签名详情链接按会话隔离、仅保留内存并随会话清除，不写入题录与观察记录。
- GB/T 7714—2025 和 2015 中文期刊格式黄金样例（含 `[J]` 标识）、三种元数据交换格式、学位论文不虚构博士类型，以及四个上游 CSL 文件的 SHA-256。

另已完成源分发包和 wheel 构建检查：样式、语言、CSL helper 和 npm 锁文件均包含在 wheel，开发期 `node_modules` 未混入包。使用生成的项目级 Codex 启动命令通过官方 stdio 客户端实测，可发现全部 39 个工具并读取 `xmu` 档案。这验证启动配置，尚不代表当前聊天已热加载新工具；客户端仍需重启 MCP 连接或新开项目聊天。

## 实校接入与查询

联调初期，在新建的 Edge 独立上下文中，只读打开 `https://kns.cnki.net/kns8s/`：返回 HTTP 200；等待页面渲染后出现“安全验证”信号，未检测到可确认的厦门大学机构标签。未提交文献检索、未下载文件、未读取学校登录表单或保存凭据。

该阶段状态为 `USER_INTERACTION_REQUIRED / INSTITUTION_UNVERIFIED`，未以首页 HTTP 200 或用户已连校内网替代目标机构识别。后续修复及真实核验结果如下。

### 可见窗口联调记录

用户在专用 Edge 窗口完成安全验证后，知网回跳到了同一 KNS 路径的 HTTP 地址。原 HTTPS 校验误拦截此回跳，出现浏览器错误页。已修复为仅对已配置来源检索路径的 GET 回跳生成本地 HTTPS 导航，保留原验证参数，不发送原 HTTP 网络请求；非来源、IdP、POST 和非标准端口仍不在该例外范围内。参数只存在于浏览器请求，不进入报告或诊断输出。

修复已通过真实 Edge 加人工夹具回归，且随后在实际专用窗口观察到一次 HTTPS 回跳升级。当前实际页面位于 `kns.cnki.net`，没有导航被拦截，处于正常来源页面；仍未找到精确的厦门大学机构标签。用户报告其自行打开的页面显示厦门大学，而专用页面机构区域为空。已将实际请求的 `piccache.cnki.net` 加入仅静态资源名单，等待新窗口复核；`t.cnki.net` 用途尚未确认，继续拦截。此结果证明安全验证后的回跳故障已排除，尚不证明机构识别或在线文献搜索已通过。

本地 `--access-check` 入口支持保留同一可见会话并由操作者主动 `verify / inspect / reload / reopen / close`；`reload / reopen` 在同一上下文应用本地配置或重开已配置入口，不清除人工验证会话。没有模型轮询或验证码自动处理。诊断只返回主机名、状态和预期机构文字的结构候选，不读取登录 DOM、密码值或身份回调参数。空页面上下文被明确标记为浏览器会话不可用。

静态资源修复后，用户确认专用页面明显改善，但右上角仍为空。进一步读取[知网官网](https://www.cnki.net/)的公开页面与[顶部组件脚本](https://login.cnki.net/tlogin/scripts/top.js)，确认其从 `login.cnki.net` 加载机构组件，配置启用了 IP 自动登录。已补齐精确认证主机和该组件请求的腾讯验证 SDK 静态主机，并将校内初始入口设为官网，检索入口继续使用 KNS。公开[机构状态脚本](https://login.cnki.net/tlogin/scripts/loginState.js)将机构名写入 `.ecp_header_unitName`；实际选择器仍须用可见厦大标签确认。

官网内置隐藏的密码输入框，原实现会因此跳过整页机构检查。已改为仅在密码输入框可见时按认证页面处理，机构标签自身也必须可见；隐藏字段的值始终不读取。人工浏览器夹具已覆盖隐藏登录框、隐藏机构名和可见登录框三种情况。

### 校内网机构识别已通过

2026-10-19 04:18 UTC，专用上下文在 `www.cnki.net` 的可见 `div.ecp_header_unitName` 中读到精确文字“厦门大学”。将此选择器固定并重载后，`verify` 返回 `ready`，证据类型为 `exact_institution_label_match`。此前候选节点的组件语义已与知网公开机构状态脚本交叉核验。

2026-10-19 04:19:31 UTC，另用官方 Python MCP 客户端经真实 stdio 子进程调用 `start_access_session`、`verify_access_session`、`close_access_session`：列出 29 个工具，机构核验返回 `status=succeeded / state=ready / institution_name=厦门大学`，随后正常关闭该 MCP 测试会话。脱敏结果见 [live-access-validation.json](live-access-validation.json)。这是校内网机构识别实测，未提交文献查询、下载全文或验证 CARSI。
