# 验收状态

日期：2026 年 10 月 19 日。此文区分软件实现、人工夹具测试和真实厦大接入，不以夹具结果代替在线能力。

## 当前交付

29 个 MCP 工具、3 个资源和 1 个工作流提示已实现。本地安装脚本、项目级 Codex 注册脚本、厦大初始档案、固定依赖和第三方样式来源清单已提供。`config.local.json` 与 `.codex/config.toml` 由脚本生成并忽略 Git；标准配置默认 Edge 临时独立上下文，接收方为 OpenAI，初始仅输出题录。

用户已确认试点学校为厦门大学、电脑已连接校内网、已有自动检索和题录采集许可，后续将补充依据及范围。项目记录这项确认，不将其扩展解释为自动全文下载或向云端模型发送受限原文的许可。当前许可档案仍等待具体依据、资源范围和有效期后完成配置。

## 自动验证

当前共 19 个测试，覆盖：

- 精确主机、URL 脱敏、未知/拒绝许可与模型服务方范围。
- 保守 DOI 去重、作者冲突保留、合并回滚、筛选关闭、人工覆盖与严格模式未知项。
- PDF 签名与结构校验、允许目录边界、解析子进程、证据页序号、文件哈希及历史快照。
- 扫描页没有文本时降级为待 OCR，任务只报部分完成，读取不标为已读全文。
- 摘要、正文、矩阵、评分理由、草稿、MCP 资源和项目导出的内容出站检查。
- 幂等键冲突、取消、重启恢复、单数据目录实例互斥。
- **真实 stdio 子进程**：initialize、tools/list、tools/call、structuredContent、资源读取和 schema 错误。
- **真实 Edge 浏览器配合人工 HTML**：精确机构识别、同页缓存分页、异步翻页、游标重复消费、机构不符和安全验证状态。网络请求由夹具拦截，没有把夹具称作知网。
- GB/T 7714—2025 和 2015 中文期刊格式黄金样例（含 `[J]` 标识）、三种元数据交换格式、学位论文不虚构博士类型，以及四个上游 CSL 文件的 SHA-256。

另已完成源分发包和 wheel 构建检查：样式、语言、CSL helper 和 npm 锁文件均包含在 wheel，开发期 `node_modules` 未混入包。使用生成的项目级 Codex 启动命令通过官方 stdio 客户端实测，可发现全部 29 个工具并读取 `xmu` 档案。这验证启动配置，尚不代表当前聊天已热加载新工具；客户端仍需重启 MCP 连接或新开项目聊天。

测试命令：

```powershell
$env:CNKI_TEST_BROWSER_CHANNEL = 'msedge'
uv run pytest -q
uv run ruff check src tests
```

本机 Chromium 自动安装在系统目录与项目目录均遇到 `vulkan-1.dll` 写入错误；已使用安装在本机的 Edge 完成浏览器测试。没有修改系统安全设置。现有 Edge 的日常个人配置未被复用。

本地性能测量通过 `uv run python scripts/benchmark.py --output docs/validation-metrics.json` 重现。每种状态/题录读取各 30 次，结果记录在 [validation-metrics.json](validation-metrics.json)。该测量不包含实际知网网络耗时，也不代表生产性能认证。

## 实校只读观测

在新建的 Edge 独立上下文中，只读打开 `https://kns.cnki.net/kns8s/`：返回 HTTP 200；等待页面渲染后出现“安全验证”信号，未检测到可确认的厦门大学机构标签。未提交文献检索、未下载文件、未读取学校登录表单或保存凭据。

因此当前状态应为 `USER_INTERACTION_REQUIRED / INSTITUTION_UNVERIFIED`，不能以首页 HTTP 200 或用户已连校内网替代目标机构识别。后续由用户在项目专用可见浏览器亲自完成网站安全验证，再根据实际机构标签维护选择器并调用核验工具。

厦大官方依据：

- [CARSI 指南](https://library.xmu.edu.cn/zy/dzzy/xwfw/CARSI.htm)：知网入口直接指向 `fsso.cnki.net`，机构 IdP 为 `idp.xmu.edu.cn`。
- [校外访问与 VPN](https://vpn.xmu.edu.cn/)：校内网、校外访问与 WebVPN 的官方说明。项目不管理 VPN 客户端。
- [2026 年修订数字资源使用管理办法](https://library.xmu.edu.cn/zy/dzzy.htm)：正文日期为 2026-10-09。符合规定的小批量科研处理与具体供应商许可需要结合核验；不依据搜索摘要中的旧版规定判断当前规则。
