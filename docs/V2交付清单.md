# V2 工程交付清单

## 要求与验收映射

| 要求 | 实现位置 | 验收依据 |
| --- | --- | --- |
| 新旧项目默认关闭，基础接口兼容 | `review_workspace.py`、`app.py` | `test_review_workspace.py` 的默认值、项目隔离与基础 prepare/save 用例 |
| schema 3 备份、回滚、目录锁 | `core.py` | `test_migrations.py`，以及任务／目录互斥用例 |
| 冻结版本、题录观测、文件哈希、解析产物 | `review_workspace.py` | 快照串用拒绝、新解析不替换引用、摘要不伪造 PDF 证据 |
| 文献卡字段、未知项、修改原因、历史 | `review_models.py`、`review_workspace.py` | 卡片历史、父版本冲突、重启重放 |
| 实际返回范围与字段／人工状态分别记录 | `review_evidence.py`、`review_preparation.py` | 屏蔽内容不计进度，任务领取时使用当前出站策略 |
| 范围、相邻上下文、重叠去重、预算后续读取 | `review_evidence.py` | 中文同义词／二元组、章节页段、预算 continuation 用例 |
| 多来源论断、反证、限定、重复报告 | `review_writing.py` | 多关系来源、重复支持分组、研究缺口必须提供范围 |
| 按问题准备材料并明确缺口 | `review_preparation.py` | 增强作业幂等、冻结卡片复用；八篇回归保留三篇问题片段缺口 |
| 稳定章节／段落／论断标识与不可变修订 | `review_writing.py`、`review_workspace.py` | 过期父版本拒绝覆盖、稳定标识归属、人工段落保留 |
| WRITE-01～12、提纲、上下文、反向提纲、分轮检查 | `writing.py`、`review_models.py` | 提示版本与结构化记录；事实／结构／语言意见分别保存 |
| 全文逐句待核查与确定性引用检查 | `review_writing.py` | 未映射句子队列、错误引文、错误引语、重复句子各自标识 |
| 模型意见与用户判断分离 | `review_writing.py` | caller_declared 角色、人工意见与模型意见分别存储，不认证语义 |
| 局部依赖、差异与核查过期 | `review_revisions.py` | 单卡／计划改动影响、修改后新提交的核查仍保留过期状态 |
| 新论文提示、采用快照前不改旧依据 | `review_revisions.py` | 覆盖复核提示、旧稿／冻结卡片重放、作品关系变化提示 |
| 关闭后暂停、重新启用须显式恢复 | `review_preparation.py`、`jobs.py` | 快速关闭再启用、重启检查点、不取消共享基础任务、无重复单元 |
| Markdown／JSON、同次 CSL 处理统一编号 | `review_export.py`、`citations.py` | 章节调序后引文编号、冻结题录冲突拒绝、关闭后导出 |
| 基础产物默认导出、显式选择增强成果 | `app.py`、`review_export.py` | 默认不含综述；历史、差异、任务结果和两个导出文件的来源策略 |

上述文件位于 `src/cnki_mcp/`，测试位于 `tests/`。人工 HTML 和人工记录仅用于工程检查，不作为知网在线或学术质量证据。

## 可复现记录与剩余验收

- [八篇真实材料隔离回归](validation/review-v2-validation.json)：八张部分阅读卡、九条工程论断、分节保存、修订、影响、重启及关闭后双格式导出。保持原材料质量警告与未覆盖片段，不称为全文精读。
- [真实 stdio 协议冒烟](validation/review-v2-protocol-validation.json)：官方 SDK 子进程，全部工具输入／输出 Schema、提示、资源以及关键增强调用通过。
- [分发包检查](validation/review-v2-package-validation.json)：wheel 中的 V2 模块、浏览器修复与源文件一致，样式和引文运行文件齐全；保存本次 wheel／sdist 的 SHA-256。
- 完整测试及 Ruff 命令、源分发包／wheel 检查说明见 [验收状态](验收状态.md)；使用流程见 [V2综述使用指南](V2综述使用指南.md)。PDF、运行库、认证材料与本地配置继续忽略 Git。
- 同一真实课题的章节质量、人工对照和专家事实支持率验收仍待完成。本轮工程验收不宣称综述质量提高，不将调用方声明的用户角色当作独立人工验收。
