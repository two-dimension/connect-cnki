## 4 逐篇观察

### C1：全球自贸协定网络与贸易隐含碳福利——基于网络关联结构的视角

该样本文献回顾先解释核算视角的变化，再梳理贸易网络研究，将两条研究线索之间的连接不足转为本研究的问题。

### C2：数字游民何以促进城乡融合？——基于空间嵌入模式的分析

该样本先区分概念界定，再比较宏观因素、微观主体与互动结果，随后将结果分化收束为机制和条件问题。

### P1：异质结工程调控Mo2C MXene助剂上H*的吸附亲和力以实现高效光催化产氢

该样本将吸附瓶颈、电子结构调控缺口、异质结设计和后续机制证据组织为连续论证。

### P2：回收造纸污泥制备低成本Ni改性碳/硅复合材料用于高效微波吸收

该样本用温度组间比较与无Ni对照区分参数优化和组分作用，并讨论相反因素及模拟条件。

### E1：一种基于生成对抗网络的稀疏CSI数据增强方法

该样本将真实采样约束对应到已有方法限制、设计选择与评价，并在结果附近交代适用边界。

### E2：区块链混币技术新进展与挑战

该综述用具体反例说明旧分类的不足，再建立有后续比较用途的分类，并将研究串联为问题和改进链。

### S1：基于生物质呋喃衍生物聚硅醚共聚物的合成及性能研究

该对照样本把前人路线及具体限制连到实验变量选择，结果按条件、数据、解释和决策推进。

### S2：过渡金属催化的不对称共轭烯丙基化反应研究进展

该对照综述按与反应难度相关的底物类型分类，在类别内部比较进展、选择性、范围及机制证据。

## 5 具体可迁移的组织方式

### 5.1 经管样本：从现实差异推导机制问题

C1 的文献回顾先展示核算视角为何发生变化，再梳理自贸协定研究如何从单一关系转向网络，最后指出两条研究线索尚未充分接合的位置（PDF 3 页）。引言中的不足、理论建模与贡献也有对应关系（PDF 2—4 页）；结尾把结果差异连接到分类应对建议（PDF 16—17 页）。值得学的是研究线索之间的关系及缺口与设计的对应，不是机械凑出三项贡献。

C2 先区分工作方式与生活方式两类概念界定，综合形成本文定义（PDF 3 页）；再组织宏观因素、微观行动及互动结果，将相反结果收束为“怎样发生、何时发生”的解释问题（PDF 4—5 页）。正文通过不同情境比较过程，结尾明确案例地域、研究方法与时间跨度的外推边界（PDF 19—21 页）。

可供 Agent 选择的动作链为：具体现象与差异 → 有关研究线索 → 尚未解释的机制或条件 → 本课题的分析视角 → 依据与边界。宏观背景只有在帮助推出具体问题时才保留。

### 5.2 理科核心：让研究缺口解释设计，让证据回答机制问题

P1 先指出某类有效助剂的具体吸附瓶颈，介绍已有调控路线，再把缺口收束为电子结构与键合关系，说明为什么选择相应异质结设计（PDF 2—3 页）。性能比较交代共同测试条件（PDF 6 页）；后续表征按电子转移、吸附变化及传输过程的不同问题展开（PDF 8—9 页），结论回扣设计和证据（PDF 11—12 页）。

P2 将吸收性能要求与材料资源化两条线索汇合到原料、组分和调控变量的选择（PDF 2 页）。结果既比较温度组，也设置无 Ni 对照，区分参数优化和组分作用（PDF 7 页）；讨论相反因素造成的非单调变化（PDF 10—11 页）。应用模拟交代模型条件，结论保留厚度、温度和频率等范围（PDF 12 页）。

可供 Agent 选择的动作链为：目标性质或现象 → 现有路径与具体瓶颈 → 设计依据 → 对照与共同条件 → 观测事实 → 机制解释及强度 → 适用范围。讨论每种表征之前，应明确它回答什么问题，不为展示仪器和图号而逐项罗列。

### 5.3 工科核心：相关工作服务设计，分类服务比较

E1 由真实使用中的稀疏与非均匀采样进入研究问题，区分已有路线的处理对象和任务目的，把限制对应到波形恢复、损失约束及去噪设计（PDF 3—6 页）。评价从恢复信号推进到下游任务，继续讨论收益与计算代价，并在结果附近保留环境和训练分布边界（PDF 11—15 页）。

E2 用旧分类无法区分的具体例子说明重新分类的必要性（PDF 3 页）。新分类用于后续角色、保护对象、机制与代价比较（PDF 7、11—12 页），并将代表性工作串成同一问题的改进链。后文归纳阶段目标，展望继续回应挑战及取舍（PDF 19—20、22—25 页）。分类标签本身不构成综合分析，分类为什么有解释力需要写出来。

可供 Agent 选择的动作链为：真实约束或任务 → 方法分类及判据 → 同维比较 → 设计响应或改进链 → 验证与代价 → 边界及下一步。综述可以按主题分类后在类内使用时间顺序，不必一律按作者、年份或国内外顺序排列。

### 5.4 对照样本：学习分类理由和比较边界

S1 展示如何从代表性路线推导实验条件及变量，S2 则按与反应难度相关的底物类型组织主题，类别内部结合时间、选择性、范围和机制证据追踪研究关系。对照样本提供组织方法上的补充，不提升为“高 IF 因而写法正确”的依据。

S1 PDF 6 页已目视核对表格和相邻比较语句，存在需要保留配对与例外的情况。这里不据此判定论文整体科学质量；对 Agent 的要求是比较数值、方向、配对和例外，不能照搬笼统优势概括。S2 的“未见报道”和乐观展望也不能自动转为本项目今日、全领域的事实判断。

## 6 从观察推导的 Agent 写作要求

本节是产品与提示设计建议，区别于第 4—5 节的成稿观察。

| 编号 | 写作要求 | 应保存或检查的内容 | 对应观察 |
| --- | --- | --- | --- |
| WRITE-01 | 写前形成论证提纲 | 本章问题、各节职责、暂定判断、依据、反证和缺口；结论随证据调整 | C1、C2、P1、E1 |
| WRITE-02 | 分类前解释判据 | 为什么这样分，是否帮助回答问题，类内与跨类采用什么比较维度 | C2、E2、S2 |
| WRITE-03 | 明确文献作用 | 作为定义、方法代表、支持、反例、条件限定或改进链；避免只排列摘要 | C1、E2、S2 |
| WRITE-04 | 先核对可比条件 | 对象、指标、单位、基线、测试条件、配对及例外；不把各研究最优值直接排榜 | P1、P2、S1、S2 |
| WRITE-05 | 分开观测与解释 | 原文事实、作者解释、Agent 综合、用户判断分别记录；机制表述与证据强度一致 | C2、P1、P2、E1 |
| WRITE-06 | 缺口能够回到材料 | 指出具体解释、条件或证据不足；范围有限时保留检索边界，不自动写“首次”或“无人研究” | C1、C2、E2、S2 |
| WRITE-07 | 限制、设计与验证对应 | 每项设计响应什么问题，哪些实验或分析可以验证；无对应处不制造必然衔接 | P1、P2、E1 |
| WRITE-08 | 保留收益、代价与边界 | 局部结果不写成普遍优越，模拟不写成实测，机制推测不写成确定因果 | C2、P2、E1 |
| WRITE-09 | 每节携带全章上下文 | 主线、前后节关系、术语表、已论证结论和待解决问题，减少拼接后的重复与跳步 | 由上述观察推导的工作流设计 |
| WRITE-10 | 写后提取实际主旨 | 用反向提纲检查每段功能、依据及与前后段关系，再删并移补 | 结构检查建议，不推定样本作者使用过该方法 |
| WRITE-11 | 事实、结构、语言分轮检查 | 润色锁定数字、单位、研究条件、否定与不确定性；实质变动重新查证 | 由条件与过强概括的观察推导 |
| WRITE-12 | 展望回应具体不足 | 说明尚缺什么验证、可怎样检验，不预测问题必然解决 | C2、E2、S2 |

“信”检查来源忠实、事实与结论力度；“达”检查分类、比较、推理与段落连接；“雅”检查准确、简洁、克制及学科习惯。先保证事实与结构，再精修语言；不以评价性修饰密度或长句数量衡量学术性。

## 7 避免把“去 AI 味”变成另一种模板

样本中也存在宏观开场、并列列举、评价性修饰和较强判断。某个词出现与否不能替代写作质量检查。是否保留一句话，要看它是否给出必要背景、具体事实、合理解释或条件，而不是只看它像不像常用套语。

不统一规定每段句数、固定四步顺序或引用数量。定义段、比较段、结果段和过渡段可以承担不同职责；要求的是读者能理解其作用。术语保持稳定，不为了避免重复而随意更换专业概念。

同样，单篇研究的引言、综述论文和毕业论文整章不能直接互套。候选结构需由研究问题和资料决定；风格样本只提供表达偏好，不补充事实依据，也不复制原句。

## 8 可选工作流与可复用指令

延续主方案第 19.2 节：增强综述辅助默认关闭，用户按项目选择；本次观察和文档保存不启用新功能，也不改变程序。用户选择综述写作后，可再选学科与文体，按需使用论证提纲、比较矩阵、文体约定和审查记录，不要求每篇都完整套用所有动作。

建议保存一张写作规划记录：研究问题、读者基础、章节职责、主分类及理由、比较维度、暂定判断、证据与例外、相邻章节关系和术语表。复用现有 ReviewPlan／ReviewSection 设计，不以增加独立模型服务作为前提。

以下指令用于后续试验，写作材料应来自用户项目，不能把本次样本中的事实移植到其他课题：

    依据提供的研究问题、文献卡与证据，先形成论证提纲：
    说明本节回答什么、如何分类、拟作何种判断、依据与例外是什么，
    以及它怎样承接前文并支持全章。

    按节写作，每段有明确的主要职责。
    先概括一组研究的共同问题，再比较条件、方法和结果，解释差异。
    区分原作者发现、综合解释与本课题选择；缺证据处保留待核查。

    写后仅依据实际正文提取各段主旨和作用，检查重复、跳步和无关材料。
    调整结构后精修语言，删除无实质作用的套话。
    润色保留事实、单位、条件和不确定性；实质改动重新核对证据。
    输出正文，以及仍需补材料或人工判断的具体问题。

对照验收使用同一批项目证据，分别生成原流程与新增规则下的小节，保存提示与版本，并留出未参与调整的课题。人工比较事实错误、条件遗漏、比较是否公平、缺口是否夸大、段落主线、修改成本和可读性。不能仅用模型自评或检测器分数宣布写作质量提升。
