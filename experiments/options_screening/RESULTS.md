# 期权市场微观结构与投资者行为：全流程对照试验

日期：2026-10-21。结论：**本轮不加入新增筛选机制**。已完成真实检索、题名摘要筛选、两组各八篇的全文材料阅读、两份实际综述、调用方逐句核对及 Markdown／JSON 导出。没有达到冻结协议中的较大提升门槛；这不等于证明这些机制在其他课题无效。

协议见 [protocol.json](protocol.json)，可复核汇总见 [final-metrics.json](final-metrics.json)。基线是当前 Codex 多查询与字面工作流，不能将现有查询编排能力算成新增机制的收益。单宽查询只用于获取消融。生产工具仍为 39 个，未注册 RRF、逐项课题判据或主动学习接口，也未更改默认筛选流程。

## 比较范围与结果

逐项预筛将同一套判断展开为 31 篇进入全文阶段、37 篇核心资格排除、10 篇待复核，待复核率 12.82%。27 篇原背景候选仍保留，其中 17 篇不满足核心资格、10 篇未知。展开发生在实验排序显示之后，不是独立语义复测，错误决定下降与错误排除率没有可用的独立估计，不能用结构更完整替代准确率提升。全文阶段把两篇噪声定价研究明确作为测量背景使用，未追改原题名摘要标签或排序。

## 实际综述与证据核对

两组均使用 V2 的版本化计划、快照、文献卡、主题比较、多来源论断、章节及同一套引用约束。初稿综合记录和扩展比较后的父版本修订均保留；材料准备作业分别返回八行矩阵。两组各保存八张卡、一个章节和事实／结构／语言三轮调用方意见；章节依赖未过期，未代填人工核查。

基线组综合价格分歧、情绪与风险溢价、持仓信息、跨市场价格发现、日内模式和噪声测量。实验组综合隐含流动性、做市对冲、券商账户分组以及噪声测量。两份稿件均保留实际样本、方法与解释层级，例如：

- 汇总持仓无法直接证明逐户身份；tick 规则推断方向不等于原始账户标签。
- 不同年份和五／十五分钟日内形态保持不可比条件，不制造直接反证。
- 非显著的成交量关系、降噪在部分合约的例外及仅样本内检验均保留。
- 台湾期货对冲条件与内地 ETF 期权分开；模型成本解释不冒充实际交易动机。
- 研究建议限定于当前八篇材料，不宣称全领域无人研究或综述质量已达标。

全文方法和所用结果均定位到实际返回的页段，文件哈希、资产及解析标识与快照相符。MCP 身份、归属和引语检查通过，只证明引用一致性。语义核对是同一调用方 Agent 的意见，没有独立评审、实证复算或逐页理解认证。正文无支持项的零计数因此不能变成质量达标率；两组均为零也不能计算“减少至少 30%”。

一篇实验组文章的检索题录年份为 2018，而 PDF 首页印刷为 2017 年第 12 期。冻结题录、排序及原始 CSL 导出保持原观测；正文及易读导出均提示冲突，正式引用前应核定印刷日期。没有静默改写历史，也没有把该问题视为已解决。

## 失败案例、共同修复与成本

这些修改改善共同获取／解析链路，**不是采用新增筛选机制**：

1. 来源详情页异步加载；等待可见控件后再判断可下载性，诊断仅保存控件结构与脱敏地址形状。
2. 实际 PDF 与 CAJ 入口可共用标识，按可见准确 PDF 文字选择，未通过 CAJ 转换获取全文。
3. 部分正常 PDF 有加密标记但默认阅读器可读，修复误拒；未输入、猜测密码或重写原件，真正需要打开密码仍停止。
4. 一篇实际 260 页，观察后显式将两组共用试验解析页数上限由 200 调至 500；50 MB 与 300 秒限制不变，生产默认仍为 200。此为事后预处理调整，不能声称全文阶段完全未经调整的预注册试验。
5. 一篇第 57 页触及内容流 token 安全上限，保留该上限、丢弃该页文本并报告缺页，其余页继续解析。所有使用均避开缺页，快照与导出保留限制。
6. 客户端曾退出并有长间隔；持久队列复核实际作业、复用文件、显式恢复已诊断失败，不把观察超时当终止或重复下载。

原始请求响应的调用数、状态、错误代码与工具耗时按类保存在汇总 JSON。时间戳跨度跨日，较长调用间隔不等于 CPU、网络、阅读或写作时间；异步作业也不能简单加到客户端耗时上。补检索只恢复原候选正常入口，不加入初始 80／80 预算、候选集合或 RRF 投票。共享读取与同一 Agent 写作使两组缺少独立可比人工计时，因此成本门槛没有通过，不能用本地排序耗时冒充全流程节省。

## 交付与采用决定

来源 PDF、完整题录、读到的正文、卡片、53 条核查意见及两组 Markdown／JSON 原始导出保留在忽略 Git 的 `data/options-screening-trial-20261020/`。易读稿为 `baseline-review.md`、`enhanced-review.md`，原始导出索引为 `review-export-index.json`，不将授权材料和认证配置提交仓库。

`finalize_trial.py` 核对冻结摘要、13 份原件哈希、卡片证据实际返回记录、八篇名单、章节和核查、快照一致性及统一 CSL 编号，再生成汇总。完整 81 项测试通过（76 项生产、5 项试验分析），Ruff 通过；真实官方 SDK stdio 冒烟仍为 39 工具／3 提示／3 资源，默认导出不包含综述。wheel 与 sdist 已检查源码一致和运行数据排除。

排序门槛失败，语义筛选及综述质量增益没有独立证据，成本门槛无法证实。按预先规则，本轮不接入新增机制；BGE 重排与 ASReview 主动学习未测试，也不接入或宣称无效。保留可复核试验和共同链路修复，独立专家标签及章节质量验收仍明确为未完成，而非本轮条件采用的既得结论。
